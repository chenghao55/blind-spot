# BLIND SPOT

> **看不見，不代表沒有危險。**

**BLIND SPOT** 是一款以方向性視野、環境遮蔽與有限資源為核心的 **2D 俯視角 Roguelike 生存逃脫射擊遊戲**。玩家從一棟隨機生成大樓的三樓出發，必須探索未知房間、搜尋補給、避開或擊敗守衛，最後抵達一樓出口。

🎮 **[立即遊玩（GitHub Pages）](https://chenghao55.github.io/blind-spot/)**

> 建議使用桌面瀏覽器，透過鍵盤與滑鼠遊玩。

## 遊戲特色

- **有限視野**：滑鼠控制約 120° 的扇形視野。牆壁、家具與關閉的門會遮擋視線，視野外完全黑暗。
- **隨機建築**：3 層樓、每層 5 × 5 個房間，共 75 個房間。每局重新生成連通關係、家具、守衛與物資。
- **探索與求生**：從三樓持刀出發，搜尋書桌與衣櫥，可能找到手槍、少量彈藥、補血藥，也可能一無所獲。
- **潛行或交戰**：守衛在房間內巡邏，依方向性視野偵測玩家。可以利用遮蔽物繞到視野外，以近戰偷襲一擊擊倒守衛。
- **移動策略**：使用 Shift 跑步，或按空白鍵快速突進。突進不能穿牆，也沒有無敵效果。
- **有限導航提示**：小地圖只記錄探索過的房間與地標；視野外移動中的守衛可能以短弧線提示大致方位。
- **永久死亡**：生命值歸零即結束當局遊戲；重新開始會生成新的大樓。

## 遊戲規則

### 探索與逃生

玩家出生於 **3F 隨機房間**，目標是找到樓梯，逐層下降至 **1F 出口**，靠近出口按 `E` 即可獲勝。**不需要清除所有守衛。**

所有房間均保證可以抵達；每次下樓所抵達的房間不生成守衛，以避免落地瞬間受到攻擊。部分家具可以搜尋，每件家具只能搜尋一次。

### 戰鬥與物資

| 項目 | 設定 |
| --- | --- |
| 玩家最大生命 | 100 HP |
| 初始裝備 | 刀，無手槍、無彈藥 |
| 普通刀傷害 | 35 |
| 偷襲 | 從敵人視野外近戰命中時必殺 |
| 手槍傷害 | 25 |
| 手槍彈匣 | 6 發 |
| 手槍射擊 | 半自動，每次點擊一發，冷卻 0.2 秒 |
| 換彈 | 1.5 秒 |
| 補血藥 | 治療 2 秒，完成後恢復 30 HP |
| 敵人生命 | 50 HP |
| 敵人射擊傷害 | 30 HP |
| 敵人瞄準時間 | 1 秒 |
| 敵人射擊間隔 | 1.5 秒 |

手槍與守衛的遠程攻擊採用 **Hitscan**，以射線碰撞進行命中判定，並有隨機散射。牆壁、家具與關閉的門會擋住射擊。

搜尋書桌或衣櫥的結果如下：

| 搜尋結果 | 尚未取得手槍 | 已取得手槍 |
| --- | ---: | ---: |
| 彈藥 1–2 發 | 35% | 約 38.9% |
| 補血藥 × 1 | 20% | 約 22.2% |
| 手槍（附滿匣 6 發） | 10% | — |
| 無收穫 | 35% | 約 38.9% |

> 找到手槍後會排除重複取得手槍的結果，依其他結果的相對權重重新分配機率。先前取得的備用彈藥會保留。

### 守衛 AI

守衛只在所屬房間內巡邏，不會開門或跨房追擊。正常情況下，守衛只會在約 120° 的視野內且沒有遮蔽時發現玩家；受擊後會立即轉向並警戒，但仍不能隔著障礙物射擊。守衛沒有聽覺偵測機制。

## 技術與執行方式

- **技術**：HTML5、CSS、JavaScript、Canvas 2D。
- **畫面**：暗色系簡約幾何風格，使用射線處理視野遮蔽與 Hitscan 射擊。
- **部署**：GitHub Pages，無需後端伺服器。
- **單檔執行**：網頁程式及使用的 MP3 音效都整合於 `index.html`。

### 本地遊玩

1. Clone 此 Repository 或下載原始碼。
2. 使用桌面瀏覽器開啟 `index.html`。
3. 在主選單選擇開始遊戲。

也可以直接從上方的 GitHub Pages 連結遊玩。

## 開發方式

本作品為 Vibe Coding 專案：先透過 **ChatGPT** 討論遊戲構想、拆解玩法並撰寫規格，再使用 **Codex** 協助實作，經由實際遊玩測試與迭代調整地圖規模、戰鬥節奏、家具配置、潛行、視野提示與 UI。
